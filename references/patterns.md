# 跨事件與時間變化

## 目的

不只逐次解釋爭執。從完整時間線主動探索：哪些行為或互動循環重複出現、同一人在相近情境的回應如何改變、未收尾的經驗可能如何影響後續，以及有哪些保護與修復因素。使用者舉例僅供理解深度，不是固定偵測項目；不先找「誰有問題」，不只找負面或只分析伴侶。

允許提出動機、心理功能與累積影響的可能解釋，例如維護自我理解、尋求確認、降低不安或減少爭執負荷，但只能在資料提供具體線索時提出；這些不是必填標籤。假說說明行為可能在當時起什麼作用，不等同證明當事人有意策劃。

## 事件、階段與總結的分工

- 事件呈現當次「具體回應 → 影響 → 後續接法／修復」，以原文及前後文支持。
- 階段在 states 的前後比較與 state_context 中，統整跨事件的相似表現、狀態變化與可能心理歷程，讓支持與反例實際改變假說，不只是串接事件摘要。
- 關係總結的你／他／共同概念組，集中解釋值得探索的心理學概念、適用範圍與練習，連回各階段和事件依據；專業定義來源不是個案證據。

不作人格診斷的原則在報告注意事項統一說明，不在每個事件重複免責。各層仍保留真正影響判斷的未知、替代解釋及補述條件；不能把通用免責句當分析，也不能為流暢刪掉實質限制。

## 比較方法

1. **先完成事件脈絡核對**。從實質互動抽取：觸發情境、雙方實際說法與行動、回應順序、後續接法、是否修復、仍未解決的部分。保留事件 ID、日期、原始證據 ID 和例外；同一次爭吵的延續、重述與編輯版本不是多個獨立案例。
2. **由資料生成候選模式**。比較相似與不同事件，尋找個人行為和雙方循環。可觀察的面向包括回應先後、需求表達、查證與更正、界線、升高、退出、協調、照顧及修復，但不限於此。相似字詞不等於相同行為，雙方也不需各有相同數量的缺點。
3. **看時間變化**。依實際轉折劃分階段，不逐月硬切、也不切三等分；同一階段可跨月，同月也可能有轉折，不預設必有升溫或磨合。各階段整理雙方明說／可能的核心需求、負荷與各自可調整的方向，相近重點跨月合併，不在階段內再逐月或逐事件列清單，並保留順暢互動與修復。比較相近觸發情境下的前後回應，追蹤開始變化的大約範圍、持續／反覆／改善及後期例外。區分沒有表達與沒有感受，不把前期未出現紀錄解作前期一定沒有。
4. **核對可比性**。考慮議題強度、指控內容、當次壓力、資料涵蓋差異及回應機會；同類情境少時縮小結論。若使用「較常」「越來越」須有可比較的事件依據；不能以後期訊息更多或文字更長推斷惡化。需要數量時寫明分母、範圍與資料限制，不設定「三次即成立」門檻。
5. **找反證與保護因素**。主動回查同類情境中沒有出現該行為、能準確表達、聽取澄清、承認錯誤、接受暫停或成功修復的事件。讓它們實際改變假說強度及適用範圍，不只列在附註。
6. **提出並比較原因假說**。將事件中的共同條件、先後順序、行為的作用和後續結果連起來。重複與一致的情境關聯，可以讓某個解釋比單次時更值得考慮；但重複只直接增強「有此模式」的支持，不自動等幅增強對特定動機的支持。說清楚是哪項新證據提升了哪個解釋的合理性。比較有資料根據的替代解釋，不必憑空列滿所有可能性，不估造機率。
7. **追蹤累積，不把先後當因果**。觀察未被澄清／修復的經驗是否被後續提及、預期或影響回應。若只見時間相伴，表達為可能相關；若當事人明說原因，也標示為當事人說法，不冒稱獨立證明。不得因後期重複就把早期歧義事件升格為已確定事實。

比較時納入 [補充事件的條件式分支](supplements.md)：說明若補述成立，模式的解釋或適用範圍如何改變，不把它混算為已確認案例。完成候選模式後讀 [溫暖敘述與探索關鍵字](tone-and-concepts.md)，檢視有無適合供後續討論的心理學概念，不能只給術語或只列缺點。

## 雙方狀態的階段比較

每個階段主動整理雙方的狀態及其前後變化，與既有需求／調整一起按整個階段整合，不再逐月或逐事件重列。不預設走向一定惡化，也不將「初期好好回話、後期情緒化」當成所有關係的預設劇本。

- **各自目前怎麼回應**：挑有資料支持的重點，例如能否確認意思、同時表達需要與理解對方、面對澄清如何調整、是否急於反駁或概括、何時需要暫停、衝突如何升高與回到討論。用具體行為描述狀態，不用「情緒化」「不成熟」代替分析，也不將合理反對、設界線或暫停當作退步。這些是可選觀察方向，不是每人每階段都填一份能力量表。
- **相較前一階段的變化**：比較相近觸發情境、實際回應順序與結果，連到前／本階段完整片段，說明變化在哪、是否只是單次線索，或未見可辨識變化。雙方各自比較，不因一方改變就推定另一方也相同。第一階段只當起始觀察，沒有更早資料就明說不能比較。
- **先確認能否比較**：交代議題嚴重度、是否遭遇更強烈的指控／傷害、回應機會、當時壓力、文字與線下內容缺口、樣本涵蓋是否不同。不能因後期情境更困難就認定回應能力變差，也不以訊息變長、變多、回覆變慢、標點或 emoji 單獨量測情緒。少量或不可比時說目前不足以判定趨勢，不強迫使用「越來越」。
- **例外與修復確實納入**：同時呈現同類情境中仍能傾聽、接受澄清、調整或修復的案例，讓它們改變結論強度。沒有取得例外不等於完全沒有；後期恢復良好也需要被看見。一次修復不直接證明穩定改善。
- **累積因素只是有依據的可能解釋**：檢視未處理的經驗是否在後續被提及、預期或影響回應。把「觀察到的回應改變」與「可能因先前衝突、負荷或不安累積」分開說，保留議題差異、當次疲累、生活壓力等資料支持的其他解釋；不能由時間順序或重複自動推導因果、動機或心理疾病。不憑空列出可能性，也不估造機率。
- **保留來源條件與時間**：只有補述支持的變化另寫「若補述成立」，不當成已觀察的趨勢。編輯前後版本不是獨立事件；解釋早期回應時用當時可見版本，不能將後來修改的內容搬回去。

用有溫度的方式理解處境，例如在實際比較支持時寫「到了這階段，你似乎更需要先確認自己的意思被聽懂，才比較有餘力接住對方」，接著交代這從哪些互動看出、例外與其他解釋。不把示例當固定答案，不從聊天狀態推論永久人格或跨情境能力。關鍵字與正式概念仍依 tone-and-concepts.md 查核；無足夠線索時保留白話觀察。

## 從多次爭吵推進到心理學／諮商的探索假說

這是主動分析工作，不是等使用者指定術語才做，也不是在結尾附一張名詞表。全文讀完後，對跨次爭吵中值得留意的模式，建立「事件 A／B／C 的共同表現 → 在哪些條件出現或消退 → 可能的心理歷程／困難 → 適合探索的概念 → 限制與實際調整」的完整連結。事件名與數量以實際資料為準，不以三次作門檻。

可以推論「特定情境下可能暫時難以同時理解自己與對方的經驗」等心理功能假說；不必先確診才有資格討論。要區分暫時狀態、這段關係內的反覆反應與跨情境穩定能力；聊天只能支持前兩者的有限推論時，不能寫成天生能力缺陷。對使用者與對方都作同樣探索，不要求一定各找一種問題。

例如，若多次獨立衝突都出現把感受直接等同對方意圖、較難考慮其他解釋、在澄清後仍難調整理解，且平靜或成功修復時能較靈活地理解彼此，可以考慮探索「衝突當下心智化暫時受限」；必須核對概念定義、重要反例、當時資訊與其他可能，不能由一次誤解或不接受使用者說法就成立，也不推導人格疾病。這只是示例，不是固定偵測結果。依 [概念指引](tone-and-concepts.md) 選真正適合的概念、附可靠來源並保持假說語氣。

若跨事件重複而缺乏平靜狀態的比較，只能說特定衝突中的表現可能與該概念相近，不能聲稱能力由好變差。若資料不足以連到專業概念，先保留具體行為模式及待探討的問題，不為滿足需求編造心理問題。已找到有依據的模式時，也不能僅用「無法診斷」略過進一步探索。

在工作資料維護「模式索引」：`pattern_id, behavior_or_cycle, scope, event_ids, source_ids, stage_comparison, supporting_evidence, counterexamples, hypotheses, alternatives, unknowns, suggestions`。假說可用「初步線索／多個事件支持／仍有重要反證」等自然語言說明依據，不當作診斷量表。資料不足時明說目前無法辨識穩定模式，不為湊章節編造結論。

## 如何寫成有溫度的結果

以心理諮商取向呈現「理解處境 → 看見具體行為 → 探索可能作用與代價 → 提出可行調整」，不用臨床權威作背書。感受可被理解，事實仍需核對；理解防衛的保護作用，不抹去對另一方的影響，也不替明確傷害找藉口。兩人的投入、負荷與責任可能不對稱。

每個值得呈現的模式要讓讀者看懂：

- **我們看見什麼**：具體行為或循環，連到不同事件及前後文。
- **它如何改變**：在哪些相近情境仍然存在、變強、變弱或出現例外；沒有變化證據就不硬寫。
- **可能發生什麼**：心理功能／動機／累積影響假說，及為何值得考慮。以「可能是在……」「一個值得留意的解釋是……」表達，不用「他其實就是……」。同段交代重要反證或未知，不把所有限制塞到文末免責句。
- **可以怎麼調整**：各自能做的小步驟、適用條件及觀察改善的方式。建議不以假說被承認為前提；共同練習以自願且安全為前提，不要求使用者單方面多承擔。

例如「你可能逐漸更需要先確認自己的經驗被公平理解，才有餘力回應情緒」只有在前後比較支持時才寫；不要把使用者這個例子當所有人的通用結論。可以建議先承認感受、再分開核對事件，但不能將承認情緒寫成同意指控，也不要求在過度負荷時繼續爭論。

友善不等於空泛安慰：先具體看見當事人已做的努力與困難，不使用「你已經很棒」「只要多溝通」等無依據套話。避免將人縮成「愛說謊」「情緒化」「逃避型」等標籤；明確支持的行為與責任仍須直接說清楚。

## 交付前核對

- 至少能由模式索引回查不同事件；單一事件只稱單次觀察，不能包裝成穩定習慣。資料僅支持某時段，就限定在該時段。
- 「事實不一致」要區分可核對的事件敘述、感受、評價及記憶差異。不能用「紀錄沒有看到」證明「現實沒有發生」。
- 模式、原因假說、建議的證據層級一致；首屏及圖解不得把假說縮成指控。箭頭描述可能循環，不暗示已證明因果。
- 不只羅列重複行為：有跨期資料時，確實比較類似情境的回應順序與結果；也呈現改善、成功修復及例外。
- 更正或新增事件後，重新核對支持與反證；模式可能需要降級、撤回或改寫，不只累積負面案例。
