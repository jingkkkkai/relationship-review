# 溫暖敘述與探索關鍵字

## 整份報告的聲音

寫得像一位認真聽過雙方經驗、願意陪人把事情理清的諮商工作者：口語、溫和、具體，有關照也有界線；不自稱心理諮商師。從首屏、事件、模式到建議都如此，不只在結尾加安慰。

- 用短段落、日常用語和自然銜接；先說讀者能理解的經驗，再說分析。避免「A 方呈現高防衛性反應」「應提升情緒調節能力」等公文式句子。
- 可以寫「當你覺得自己又被誤解時，可能很難一邊替自己說清楚，一邊照顧他的難過。這不代表你不在乎；不過，如果回應只剩下澄清，他也可能更難感受到你願意聽。」實際使用前須有事件支持，不把這句變成通用答案。
- 每個理解都連到具體紀錄或清楚的條件式敘事；不代讀者宣稱「你一定很受傷」，可說「如果那時你覺得委屈，這份感受值得被聽見」。不因溫柔而淡化辱罵、施壓或忽略拒絕。
- 對雙方分別表達關照，不預設他會閱讀，也不要求使用者把文字傳給他。標題用「給你的話」「給他的話」，稱呼依下方 [稱呼與人稱](#稱呼與人稱)，避免審判式評語。
- 鼓勵與安慰以看見努力、承認困難、保留自主與可行小步驟為主；不保證變好、復合、原諒，不用「雙方都只是太愛對方」「只要溝通就好」等套話。肯定不等於免責。
- 責任寫成對具體行為的承擔，不寫人格好壞；不預設兩人責任相同。資料不足時可以支持感受，但不能硬編一個人的努力或缺點。

## 稱呼與人稱

預設稱呼固定為「你」與「他」，整份報告不換：

- 「你」＝匯出這份對話、閱讀報告的使用者；「他」＝選定的對話對象。報告最上方由 renderer 自動註明這兩個稱呼各指誰，不必在每段重複說明。
- 不論段落寫給誰看，「你」永遠是使用者、「他」永遠是對話對象。寫他的需要、他可以承擔的部分、給他的話時，也用「他」當主詞，不改成「對方」「我」，也不把他寫成「你」。
- 不用「對方」「另一方」「我」指稱兩人；「對方」是相對說法，讀者會分不清是誰的對方。需要一起說時用「你們」「兩個人」「雙方」。
- 使用者另外指定名稱時（例如「小明／阿芳」），標題、內文與最上方的稱呼說明都改用指定名稱；未指定一方就維持該方預設稱呼。
- 聊天原文、直接引文裡的「我」「你」照原樣保留，不改寫。引用時用引號標清楚是誰說的，例如：他說「我只是提一下」。

| 寫法 | 例子 |
| --- | --- |
| 不要 | 對方可以為表達不清楚負責；這不表示他有意忽略我的感受。 |
| 要 | 他可以為沒把提議說清楚負責；這不代表他故意忽略你的感受。 |
| 不要 | 給對方的話：把需要說清楚，不代表你很麻煩，而是讓對方有機會理解。 |
| 要 | 給他的話：他想晚點出門、想避開吵的地方，這些都可以說出來。把需要講清楚不是麻煩，反而讓你們更好商量。 |

## 讓人一讀就懂

讀者是一般人，不是研究者。每句寫成朋友坐下來聊天時說得出口的話：

- 先講重點，再補理由；一句只講一件事，超過兩個逗號就考慮拆開。
- 少用書面與統計用語。常見替換：「可辨識／可定位」→「看得出來／找得到」；「本表／本次」→「這裡／這次」；「未確認」→「沒看到」；「推定／判定」→「斷定」；「回合」→「次」；「指涉不明」→「看不出在說什麼」；「承接」→「接住」；「呈現」→「看得出」；「依據」可保留在連結文字，正文改說「從哪些訊息看出來」。
- 限制與不確定照樣要寫，但用白話：「樣本太少，不能認定動機」→「只有這幾段對話，看不出他心裡真正怎麼想」。
- 少在句子裡解釋報告格式（例如「此欄」「本表」「下方依據」），讓標題和連結自己說話。
- 寫完自問：把這句念給當事人聽，他需要停下來想一下才懂嗎？需要就改。

## 交付前的一次完整潤稿

分析與依據核對完成後，對模型撰寫的所有讀者文字作一次完整編輯，再輸出 HTML。這一步只改善表達，不重新閱讀全部原始資料、不反覆重寫整份分析。檢查範圍包含首屏重點、事件、模式、條件式補述、責任與建議、鼓勵、心理學概念及片段標題；不能只修開頭。

- **先把一句話說完整**：主詞、做了什麼、影響是什麼要清楚。把連續名詞換成動作，例如「進行情緒需求的承接」改成「先回應對方的難過」。不要為口語而省掉必要的前因後果。
- **長句拆開**：一個句子主要說一件事，過多「而／並／同時／因此」就拆成兩三句。保留因果強度，不把「同時出現」潤成「導致」。
- **避免翻譯腔與官腔**：不用「此互動呈現出」「於該情境下」「在……的部分」「進行……的處理」堆疊句子。直接說誰在什麼時候做了什麼，以及讀者可以怎麼理解。
- **稱呼與視角一致**：全文依 [稱呼與人稱](#稱呼與人稱) 只用一組稱呼，同一段不在「你」「我」「對方」「使用者」「A 方」間切換。引用與原文不改稱呼。
- **讓轉折有交代**：先交代當時發生什麼，再談感受、可能解釋與建議，不從兩段筆記硬接成跳躍結論。使用「不過」「後來」等銜接時，確保前後關係確實存在。
- **不疊不確定詞**：「可能看起來似乎有……傾向」改成「一個可能的解釋是……」，接著清楚交代支持與限制。不能為流暢刪掉「如果補述成立」「尚未確認」或把假說寫成事實。
- **溫暖要具體**：把空泛的「應改善溝通」改成適合該事件的一個小做法；支持的話要連到實際努力與難處，不堆套話，不淡化已確認的傷害。
- **專業詞只在需要時用**：先用白話說意思，再在探索概念欄列名詞；不要用術語取代句子的解釋，也不替個案擅自換成更強烈的概念。
- **保護原文與依據**：聊天原文、直接引文、日期、事實、責任歸屬、證據 ID、網址及完整脈絡連結不因潤稿改變。發現語意不明先回查相關來源，不替當事人補話。

虛構示範（僅示範句法，不是每份報告必寫的解讀）：

- 生硬：「A 方在面對誤解時，呈現出優先進行事實澄清而延後情緒承接之模式。」
- 自然：「當你覺得自己被誤解時，往往會先把事情說清楚。他的難過，要等你說清楚之後才比較有餘力回應。」這個頻率與先後順序只有資料支持時才寫，不能因例句自然就套用。

潤稿後對照原分析核對：每句是否易懂、前後是否接得上、摘要是否與正文一致、不確定性及各自責任是否保留。紀錄一次已檢查即可，不用輸出修稿過程或要求使用者先挑出所有病句。沒有實際讀到整份讀者文字，就不能宣稱已完成全文潤稿。

## 心理學／諮商關鍵字：供探索，不替人定性

固定分三個部分，不合成一份不分對象的清單：

1. **關於你**：以使用者自己的可觀察行為、負荷及需要為依據，指出可自行理解或練習的部分。
2. **關於他**：以他的具體表現為依據，仍採假說語氣，不因他沒參與就作更確定的判斷，也不要求使用者去診斷、治療或說服他。
3. **關於彼此互動**：針對雙方互動循環、協調與修復；「共同」不代表責任各半。只有一方有證據的傷害行為不可搬到共同欄稀釋責任。

每組各自連到相關事件、支持與反例，解釋概念為何可能有幫助及可以探討什麼。三組都呈現，但沒有適用概念時說明資料不足或目前沒有必要硬套，不為對稱強迫兩人各有一種問題。同一概念確實對雙方都適用時可分別說明差異，不機械複製；跨組共用定義可引用同一來源。

在模式分析後主動檢視是否有適合的概念，挑少量真正有助理解的關鍵字，不硬湊、不把所有行為貼上術語。不限於防衛或合理化，也可涉及修復、需求表達、相互支持及其他資料支持的主題。

每個有依據的跨事件模式，主動評估能否進一步連到可能的心理歷程或困難，而非只提供搜尋詞。讀者應看懂「哪些事件呈現相似表現，為什麼這個概念值得探索，以及還不能確定什麼」。這是非診斷的案例假說，不是禁止思考心理原因。明確區分諮商概念、一般行為描述與臨床診斷，不把一般概念稱作已罹患的疾病。

可查核的起點（不是個案判斷或必選概念）：[Anna Freud 的心智化介紹](https://www.annafreud.org/training/health-and-social-care/mentalization-based-treatments-mbt/mentalization-based-treatment-adults/about-mbt/) 說明心智化涉及理解自己與他人的心理狀態。該概念的存在不證明此個案能力下降；若要提出「暫時下降／壓力影響」的具體說法，仍須另外查核相應的研究、情境限制與個案前後比較。不得因來源提到某種疾病，就順帶把疾病套到當事人。

每個條目應包含：

1. 中文關鍵字，必要時加原文，以及一兩句白話說明。
2. 連到事件 ID、原紀錄及重要反例：哪些相似之處讓這個概念值得探索？不是只以一句模糊話套概念。
3. 明確的探索措辭：「這些互動有些地方，可能與……概念相近，可以作為後續討論方向。」不是「A 就是……」「已證明 A 有……」。若依賴補述成立才吻合，保留同一條件。
4. 適用限制：同一表現也可能有其他原因；不由關鍵字診斷心理疾病、依附類型或固定人格。以操控、煤氣燈等具強烈指控含義的詞為主要標題，須先核對定義與意圖／持續情境是否有足夠支持；不足時改用具體行為與較中性的探索詞，不能靠「可能」包裝指控。
5. 可帶去討論的一個問題或小練習，讓關鍵字幫助理解，而非成為指責對方的武器。

對選中的概念查核可靠專業來源的定義與適用範圍，例如專業心理學組織、正式研究或具資格專業機構的公開資料；正文附可點擊來源。一般理論只能支持概念說明，不能充當這兩人的個案證據。不得捏造專業術語、引文或連結，不將私人原文、姓名放進搜尋。沒有查核能力時，明說概念尚未核對，降為待查詢的探索用語，不寫權威定義或確定對應；無合適概念時坦白說明即可。

## 章節名稱

依 [輸出標題表](output.md#標題用簡短白話) 使用簡短、日常的章節名稱；事件、階段與條目標題也先說讀者看得懂的重點，專業用語與限制在正文解釋。縮短標題不縮減分析內容，不把探索改成判決。

## 事件內的互動反應

每個事件設「這次雙方怎麼回應」，分你／他呈現當次具體回應、影響與修復。先寫「說了什麼或做了什麼 → 對談話有什麼影響 → 後來如何接住／卡住／修復 → 可以嘗試的小調整」，連到當次原文及必要前後文。支持、合理澄清、設界線、暫停與合作都值得看見；不只列問題，也不要求雙方各有一個缺點。

- 用白話說明當次歷程，例如有依據時寫「這次先急著解釋本意，對方在意的安排暫時沒有被回應，後來才重新協調」。不以名詞或「無法由單次判定人格」取代觀察。若真的需要短句探索當下可能的反應，交代依據與實際影響即可，不必每次跑一份心理學概念適配表。
- 「不作心理診斷、不以單次互動判定人格」在注意事項統一說明；事件不固定加同一句提醒，也不用「只能說單次」「不能推定人格／能力」作為每項收尾。不要機械刪掉所有不確定性：缺引用、未提供電話內容、指涉不明或補述未確認等會實質影響當次結論的限制，仍緊鄰保留。
- 反應欄提供具體內容；只有資料真的缺失時才說明當次缺口。無實質反應可辨時保留該方並說清楚原因，不用空泛的診斷免責填滿欄位。summary 可在已有完整 items 時留空，避免先介紹一次、條目再重說一次。
- 同一反應是否反覆出現、前後期是否改變、可能與哪些心理歷程相關，放階段變化的 states／state_context，比較不同事件與反例。一般理論的定義、較完整的個案假說和可探索的關鍵字，集中在關係總結的你／他／共同概念組。單次事件保留回查入口，不複製整段概念定義或強迫事件各配一個術語。
- 分工是表達層次，不降低分析深度。階段和總結仍應在有支持時主動提出可修正的心理歷程假說，說明支持、反例與其他解釋，依前節核對概念來源；不能以「無法診斷」跳過已有依據的探索。沒有足夠跨事件線索時，不把當次反應升格成穩定模式。
- 若補述成立才有的事件解讀，仍使用緊鄰標示的條件式分支；合理反對、澄清與設界線不自動等於防衛。責任仍按具體行為及影響說清楚，理解處境不抹去傷害。

## 必備的關係回顧收尾

依 [閱讀輸出](output.md) 分別呈現：雙方各自責任、各自可改善方向、各自值得肯定及支持的話，以及整段關係的總結與下一步。它們不是互相替代：不能只有練習而沒有責任，也不能只有責任而沒有對人的理解。責任和支持不必篇幅相同，資料不足就說明，不硬配對。

## 狀態變化的敘述

狀態、變化與可能原因分開說：先描述各階段的具體回應，再比較相近情境，最後才探索負荷／未解經驗等可能因素。把「越來越情緒化」換成有支持的回應先後、升高與修復變化，避免將人縮成標籤。也看見改善、仍能好好談的時候及需要休息的合理性；狀態可變，不直接推斷永久能力或人格。不可比或不足時坦白說明，第一階段不補造更早狀態。每段保留明說／觀察／推論／補述條件，不能靠末尾免責句抵銷正文的確定指控。具體呈現欄位依 output.md。
