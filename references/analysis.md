# 分析與驗證

## 覆蓋與來源

開始閱讀前必讀 [完整閱讀與交付檢查](reading-gate.md)。**全部選定文字、補述與可讀圖片處理完成前，不產出分析報告；不能以「這只是部分分析」提前交付。** 未完成時只回報閱讀進度、不可讀內容與繼續方式。

先建立全範圍清單：日期、原始紀錄數、可讀圖片、音訊、影片、其他附件、缺檔與解析失敗。記錄每個文字區段與附件的「已讀／純轉傳排除／未讀／無法讀」。檔案被列出、解析成功或產生摘要，不等於模型完整閱讀。

長資料按日期及實際大小分段，跨邊界事件保留前後脈絡，建立可延續的 coverage 清單、每日時間線、事件與證據索引。模型需讀過每個實質文字區段；抽樣只適合驗證解析，不替代全文分析。完整來源留工作資料夾；主分析 HTML 不需重印全部訊息，另依 conversation-review.md 交付全部對話回顧，確保讀者可查完整脈絡。

原始空白日可註明無可讀訊息，不虛構活動；跨日事件不是一天一事件。事件選擇涵蓋重要正向互動與困難，避免所有平穩日常被壓成一句、所有爭吵卻細寫。

## 解讀

每個事件視需要描述起因、發展、轉折與收尾，雙方明說的需求與立場、具體行為與影響、各自責任、做得好的地方、可改善方向、依據與缺口。資料不足時縮小結論，而非套固定心理標籤。關係類型依使用者說明及可確認資料，不預設所有對象是伴侶；朋友間的玩笑、親密稱呼不能直接證明浪漫或性意圖。

### 上下文核對：先讀完整片段，才命名行為

觸發敏感解讀的句子只是查核起點，不是結論。對性邀約、曖昧、背叛、欺騙、操控、威脅等判斷，交付前必須逐項完成：

1. 回到原始紀錄，從引出話題的位置讀到回應、澄清或收尾；至少包含雙方完整回合。不能只固定抓前後幾句：前文尚未找到指涉、後文尚未收尾，就向外延伸，必要時跨日、跨分段、回查附件或被回覆訊息。沒有取得的脈絡明確列缺口。
2. 確認誰說、對誰說、在回覆什麼，是否引用他人、轉述電影或朋友、假設問題、否定句、反諷、雙關、語音辨識錯誤或既有玩笑。沒有回覆關聯資料時不得猜指涉。表情和笑聲只是線索，不能單獨證明「一定是玩笑」。
3. 先寫可觀察的內容，再比較有原文支持的解讀與反證。對方的接話、後續安排或澄清可以支持或削弱邀約解讀，但不能直接證明內心意圖；不能只挑支持最嚴重解讀的句子。沒有資料支持的替代故事也不必編造。
4. 內部保留查核紀錄：候選判斷、上下文紀錄 ID 範圍、實際指涉、支持證據、反證／其他合理解讀、缺口及最後採用的說法。正式報告的依據要涵蓋關鍵前後回合，不只連到觸發句。
5. 明確對特定人的性行為提議、有足夠上下文支持時，才描述為性邀約；關鍵字、疑問句、親密語氣或使用者／第三人指控不足以單獨成立。仍歧義時，寫「這句話的指涉／用意無法從現有紀錄確認」，不列成已發生的性邀約。不為保持中立而淡化有明確證據的傷害行為。
6. 不把不確定的動機當作已證實的道德責任或關係風險。允許依跨事件證據提出原因假說與探索性建議，方法見 [跨事件與時間變化](patterns.md)；建議要基於可觀察行為，即使動機假說不成立也合理，不要求當事人先承認被推測的動機。不能正文標註「可能」，卻在概覽或最終回顧改成確定事實。若一個澄清會實質改變結果，先問中性的問題，例如「這裡是在接哪個話題？」避免「你為什麼邀約他？」等預設有罪的問法。

虛構判讀例子：

- 前文討論電影台詞，甲引用「今晚來我家？」、乙問下一句、甲接續台詞：應描述為討論／引用台詞，不能據引用句判定對乙邀約。
- 甲問「他是不是在約你上床？」、乙答「不是，是約打球」：甲的疑問不是甲對乙的性邀約；乙的說法是澄清主張，不代表已證明第三人的全部意圖。
- 甲向乙明確提出性行為，乙拒絕，甲仍持續要求：應具體描述提議、拒絕及持續要求，不因後面出現「哈哈」而自動撤銷判斷。
- 只有「來我家睡」且前後資料缺失：不能確認是住宿安排還是性提議，保留未知；不要在責任或總結指控越界。

區分：拒絕／暫停／睡覺／離開／分手，與辱罵／無依據指控／物品施壓／強迫持續爭論。理解需求不能合理化傷人的做法；說明衝突循環也不能把具體責任模糊成各半。對可能的脅迫或安全疑慮描述具體行為，不預設共同溝通練習適用。

整體回顧：關係如何變化、各自做得好的地方、期待差異、重複互動、修復方式、各自可做的小練習與可共同練習的部分。使用「這段紀錄顯示」「可能」「仍不知道」等符合證據的措辭，不揣測內心定論。沒有爭執也能分析合作、照顧、回應和界線。沒有證據支持改善項目時不硬找缺點。

證據類型顯示為：`訊息紀錄`、`訊息中的主張`、`當時筆記`、`事後回憶`、`推論`、`未知`。一句訊息中可同時有觀察與主張，需在解讀區分。不要為每句話發明信心百分比。

## 更新與交付檢查

事件分析後必讀 [跨事件與時間變化](patterns.md)，再形成整體結論。行為、跨事件規律與原因假說分層陳述；不因無法確定動機而刪去有依據的探索。

1. 對照來源首尾、日期範圍、數量與 coverage，確認無漏分卷、亂碼、錯年、錯時區、掉多行與誤去重。
2. 回查重要結論與各自責任，確認證據支持且反證已納入。涉及敏感意圖的結論必須通過上述上下文核對，逐項檢查首屏重點、事件、責任、練習與整體回顧是否把未知升格成事實。推論不得只引用另一個摘要作來源。
3. 核對所有事件 ID、訊息／補述 ID、圖片引用及 HTML 錨點，來源索引能找回原位置。
4. 明確列未讀音訊／影片、缺檔、電話內容、線下未知。分析範圍與完整性聲明和實際 coverage 一致。
5. HTML 內容與核對後的分析一致，無占位文字；繁體中文、日期、字型、長文、展開欄位、事件導航及手機窄版均合理。可用瀏覽器時實際開啟檢查，不能時標示未做視覺驗證。
6. 新資料或更正變更相關事件後再核對整體回顧、跨事件模式、原因假說與階段變化；撤回誤判時，同時清除由它衍生的責任、建議與關係走向判斷，不只換成較柔和措辭。不得保留互相矛盾的新舊判斷。主文不寫修訂流水帳。

保留工作資料以便同一 session 更正；不要承諾跨 session 會自動記住或讀得到。後續更正時若原來源不可用，明說需要提供相關材料。
